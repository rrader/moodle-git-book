У цій практичній роботі ми створимо модуль комп'ютерного зору для безпілотного автомобіля (Self-Driving Car) — алгоритм розпізнавання та класифікації сигналів світлофора на базі бібліотек OpenCV та NumPy у кольоровому просторі HSV.

🚗 Контекст інженерної задачі

Безпілотний автомобіль повинен у реальному часі сприймати сигнали світлофорів незалежно від часу доби, сонячних відблисків та погодних умов. Для надійної сегментації кольорів у комп'ютерному зорі замість звичного RGB використовують простір HSV (Hue, Saturation, Value).

🎯 Мета роботи:

  • Навчитися конвертувати зображення з колірного простору BGR у HSV.
  • Зрозуміти особливість «кільцевого» спектра червоного кольору в просторі Hue та об'єднувати бітові маски через cv2.bitwise_or.
  • Застосувати морфологічну фільтрацію шуму (cv2.morphologyEx).
  • Розробити модуль прийняття рішень для системи автопілота: STOP (Червоний), READY (Жовтий) та GO (Зелений).

🌈 Чому саме HSV для дорожніх умов?

У звичайній колірній моделі RGB зміна освітленості (наприклад, яскраве сонце або сутінки) одночасно змінює всі три канали R, G і B. Це ускладнює налаштування фіксованих порогових значень.

Простір HSV розділяє візуальну інформацію на три незалежні складові:

  • Hue (Тон, відтінок): чистий колір по колу від 0° до 360° (в OpenCV масштабується в діапазон $0 \dots 179$).
  • Saturation (Насиченість): глибина кольору ($0 \dots 255$).
  • Value (Яскравість): освітленість ($0 \dots 255$).
⚠️ Важлива інженерна деталь: Специфіка червоного кольору в HSV

У колірному колі червоний колір розташований на стику 0° та 180°! Тому для надійного виявлення червоного кольору в OpenCV необхідно створити два окремі діапазони та об'єднати їх логічним АБО:
1) lower_red1 = [0, 100, 100] ... upper_red1 = [10, 255, 255]
2) lower_red2 = [160, 100, 100] ... upper_red2 = [179, 255, 255]

💻 Покроковий код розпізнавання світлофора

import cv2
import numpy as np

def detect_traffic_light_state(image_bgr):
    """
    Визначає стан світлофора: RED, YELLOW, GREEN або UNKNOWN
    """
    # 1. Конвертуємо зображення в колірний простір HSV
    hsv = cv2.cvtColor(image_bgr, cv2.COLOR_BGR2HSV)

    # 2. Визначаємо діапазони кольорів у HSV
    # Червоний (дві маски через обгортання кола)
    lower_red1 = np.array([0, 120, 100])
    upper_red1 = np.array([10, 255, 255])
    lower_red2 = np.array([160, 120, 100])
    upper_red2 = np.array([179, 255, 255])

    mask_red1 = cv2.inRange(hsv, lower_red1, upper_red1)
    mask_red2 = cv2.inRange(hsv, lower_red2, upper_red2)
    mask_red = cv2.bitwise_or(mask_red1, mask_red2)

    # Жовтий (Hue приблизно 15..35)
    lower_yellow = np.array([15, 120, 100])
    upper_yellow = np.array([35, 255, 255])
    mask_yellow = cv2.inRange(hsv, lower_yellow, upper_yellow)

    # Зелений (Hue приблизно 40..90)
    lower_green = np.array([40, 100, 100])
    upper_green = np.array([90, 255, 255])
    mask_green = cv2.inRange(hsv, lower_green, upper_green)

    # 3. Морфологічне очищення від випадкового шуму (Morphological Opening)
    kernel = np.ones((5, 5), np.uint8)
    mask_red = cv2.morphologyEx(mask_red, cv2.MORPH_OPEN, kernel)
    mask_yellow = cv2.morphologyEx(mask_yellow, cv2.MORPH_OPEN, kernel)
    mask_green = cv2.morphologyEx(mask_green, cv2.MORPH_OPEN, kernel)

    # 4. Підрахунок активних пікселів для кожного кольору
    red_count = cv2.countNonZero(mask_red)
    yellow_count = cv2.countNonZero(mask_yellow)
    green_count = cv2.countNonZero(mask_green)

    counts = {
        "RED": red_count,
        "YELLOW": yellow_count,
        "GREEN": green_count
    }

    dominant_color = max(counts, key=counts.get)
    max_pixels = counts[dominant_color]

    # Мінімальний поріг для впевненого спрацьовування
    MIN_PIXEL_THRESHOLD = 150

    if max_pixels < MIN_PIXEL_THRESHOLD:
        return "UNKNOWN / OFF", counts, None

    # Рішення для автопілота
    actions = {
        "RED": "🛑 STOP (Зупинка)",
        "YELLOW": "⚠️ READY / CAUTION (Увага)",
        "GREEN": "🟢 GO (Рух дозволено)"
    }

    return actions[dominant_color], counts, (mask_red, mask_yellow, mask_green)

# Демонстраційний запуск на тестовому зображенні
if __name__ == "__main__":
    # Завантажуємо зображення світлофора (traffic_light.jpg)
    img = cv2.imread("traffic_light.jpg")
    if img is not None:
        action, stats, _ = detect_traffic_light_state(img)
        print(f"Система автопілота: {action}")
        print(f"Статистика пікселів: {stats}")
    else:
        print("Зображення не знайдено, запустіть скрипт із фотографією світлофора!")
