📐 Теоретичні відомості: Лінійна регресія та метрика MSE

Лінійна регресія (Linear Regression) моделює зв'язок між залежною змінною (цільовим показником $y$) та однією або кількома незалежними змінними (ознаками $x$):

ŷ = b₀ + b₁x

де ŷ — спрогнозоване значення, b₀ — зсув (intercept), а b₁ — коефіцієнт нахилу (slope/weight).

Середньоквадратична помилка (MSE — Mean Squared Error):

Для оцінки того, наскільки прогнози моделі близькі до реальних значень, використовують метрику MSE. Вона обчислює середнє значення квадратів різниць між реальними значеннями $y_i$ та прогнозами моделі $\hat{y}_i$:

MSE = (1 / n) · Σ (yᵢ - ŷᵢ)²
  • Чим менше значення MSE, тим точніша модель.
  • Піднесення до квадрата гарантує, що помилки з різними знаками не компенсують одна одну, а також сильніше штрафує великі відхилення.

Крок 2. Код моделі та інтерфейсу (python/p1.py)

Створіть файл python/p1.py. У ньому ми завантажимо набір California Housing, візьмемо ключову ознаку (середній дохід домогосподарства MedInc) та навчимо лінійну модель передбачати вартість житла:

import streamlit as st
import pandas as pd
import numpy as np
import matplotlib.pyplot as plt
from sklearn.datasets import fetch_california_housing
from sklearn.model_selection import train_test_split
from sklearn.linear_model import LinearRegression
from sklearn.metrics import mean_squared_error

st.set_page_config(page_title="Лінійна регресія: California Housing", layout="wide")

st.title("🏡 Прогнозування вартості житла: Лінійна регресія")
st.write("Навчання моделі лінійної регресії за допомогою Scikit-Learn та оцінка середньоквадратичної помилки (MSE).")

# 1. Завантаження даних
@st.cache_data
def load_data():
    housing = fetch_california_housing(as_frame=True)
    df = housing.frame
    return df

df = load_data()

st.sidebar.header("⚙️ Налаштування експерименту")
test_size = st.sidebar.slider("Частка тестової вибірки (Test Size):", 0.1, 0.4, 0.2, 0.05)
random_seed = st.sidebar.number_input("Random Seed:", value=42, step=1)

# Вибираємо ознаку MedInc (середній дохід) та цільову колонку MedHouseVal
X = df[['MedInc']]
y = df['MedHouseVal']

# 2. Поділ на Train / Test
X_train, X_test, y_train, y_test = train_test_split(
    X, y, test_size=test_size, random_state=random_seed
)

# 3. Навчання моделі
model = LinearRegression()
model.fit(X_train, y_train)

# 4. Прогнози
y_train_pred = model.predict(X_train)
y_test_pred = model.predict(X_test)

# 5. Оцінка за MSE
mse_train = mean_squared_error(y_train, y_train_pred)
mse_test = mean_squared_error(y_test, y_test_pred)

# Виведення результатів
st.subheader("📊 Результати навчання моделі")

col1, col2 = st.columns(2)
with col1:
    st.metric("MSE на тренувальній вибірці (Train MSE):", f"{mse_train:.4f}")
with col2:
    st.metric("MSE на тестовій вибірці (Test MSE):", f"{mse_test:.4f}")

b0 = model.intercept_
b1 = model.coef_[0]
st.info(f"📐 **Отримана формула лінійної моделі:** `ŷ = {b0:.4f} + {b1:.4f} · MedInc`")

# 6. Візуалізація
st.subheader("📈 Графік лінії регресії")
fig, ax = plt.subplots(figsize=(10, 5))

# Відображаємо підвибірку точок для швидкого рендерингу
sample_idx = np.random.choice(len(X_test), size=min(300, len(X_test)), replace=False)
ax.scatter(X_test.iloc[sample_idx], y_test.iloc[sample_idx], alpha=0.4, color="tab:blue", label="Фактичні дані (Test)")

# Лінія регресії
x_line = np.linspace(X['MedInc'].min(), X['MedInc'].max(), 100).reshape(-1, 1)
y_line = model.predict(x_line)
ax.plot(x_line, y_line, color="red", linewidth=2.5, label="Лінія регресії (Model)")

ax.set_xlabel("MedInc (середній дохід, $10,000s)")
ax.set_ylabel("MedHouseVal (вартість будинку, $100,000s)")
ax.legend()
ax.grid(True, linestyle="--", alpha=0.5)

st.pyplot(fig)

Крок 3. Запуск у браузері через Stlite WebAssembly (python/p1.html)

Щоб користувачі могли відкривати наш Python-застосунок прямо у звичайному браузері без запуску локального сервера, створимо файл python/p1.html: 

<!DOCTYPE html>
<html lang="uk">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Лінійна регресія — Stlite</title>
    <link rel="stylesheet" href="https://cdn.jsdelivr.net/npm/@stlite/mountable@0.58.1/build/stlite.css" />
</head>
<body>
    <div id="root"></div>
    <script src="https://cdn.jsdelivr.net/npm/@stlite/mountable@0.58.1/build/stlite.js"></script>
    <script>
        stlite.mount({
            requirements: ["scikit-learn", "pandas", "numpy", "matplotlib"],
            entrypoint: "p1.py",
            files: {
                "p1.py": {
                    url: "./p1.py"
                }
            }
        }, document.getElementById("root"));
    </script>
</body>
</html>

Крок 4. Тестування та публікація на GitHub Pages

  1. Перевірте локальну роботу, запустивши локальний HTTP-сервер: 
    python -m http.server 8000
    Відкрийте адресу http://localhost:8000/python/p1.html та переконайтеся, що Streamlit-застосунок успішно завантажується та будує графік.
  2. Зафіксуйте зміни через Git та надішліть до репозиторію вашого персонального сайту: 
    git add python/
git commit -m "feat: додано практичну роботу з лінійної регресії на Stlite"
git push origin main
  3. Додайте кнопку або посилання на python/p1.html на головній сторінці або в розділі проєктів вашого сайту.
