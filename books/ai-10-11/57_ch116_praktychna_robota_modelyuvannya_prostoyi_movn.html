Мовні моделі (Language Models, LM) — це фундаментальний клас алгоритмів штучного інтелекту, призначений для математичного моделювання людської мови. Їхнє базове завдання — передбачати наступне слово (next-token prediction), враховуючи попередній контекст. Хоча сучасні моделі (як-от GPT-4 чи Claude) побудовані на глибинних нейромережах-трансформерах, ключовий принцип їхньої роботи можна зрозуміти та змоделювати на класичній статистичній N-грамній моделі.

💡 Як «думає» авторегресійна мовна модель?

Мовна модель не «розуміє» текст у людському сенсі. Вона обчислює умовну ймовірність появи наступного слова:
P(wₜ | wₜ₋₁, wₜ₋₂) — «яка ймовірність слова wₜ, якщо попередніми словами були wₜ₋₂ та wₜ₋₁?»

🎯 Мета роботи:

  • Зрозуміти концепцію контекстного вікна (Context Window) та передбачення наступного токена.
  • Навчитися готувати текстовий корпус для задачі передбачення слів.
  • Побудувати триграмну мовну модель за допомогою візуального інструменту Orange Data Mining (або коду на Python).
  • Дослідити оцінку якості мовної моделі через матрицю помилок та метрику точності (Accuracy).

📐 Теоретичні основи: Від N-грам до генеративного ШІ

Будь-який текст можна розбити на послідовні вікна фіксованої довжини — N-грами:

  • Уніграма (Unigram, N=1): окремі ізольовані слова без контексту.
  • Біграма (Bigram, N=2): пари слів (наприклад, ["штучний", "інтелект"]). Передбачення слова на основі 1 попереднього.
  • Триграма (Trigram, N=3): трійки слів (наприклад, ["мова", "програмування"] → "Python"). Перші два слова утворюють Контекст (Features), а третє — Цільовий токен (Target).
Приклад формування навчальних прикладів із речення:

«Глибоке навчання відкриває нові можливості для науки»
1. Контекст: ["Глибоке", "навчання"] → Ціль: "відкриває"
2. Контекст: ["навчання", "відкриває"] → Ціль: "нові"
3. Контекст: ["відкриває", "нові"] → Ціль: "можливості"

📋 Порядок виконання роботи в Orange Data Mining

Крок 1. Підготовка навчального корпусу текстів

  1. Підготуйте текстовий файл (наприклад, уривок наукової статті чи художнього твору обсягом 300–500 слів).
  2. Сформуйте таблицю (CSV), що містить дві колонки:
    • context (текстовий рядок із двох послідовних слів);
    • next_token (одне наступне слово, яке має бути передбачене).

Крок 2. Побудова моделі в Orange Canvas

Створіть на робочому полотні Orange наступний конвеєр обробки:

[ CSV File ] → [ Select Columns ] → [ Preprocess Text / Bag of Words ] → [ Logistic Regression / Naive Bayes ] → [ Test & Score ]
  1. Select Columns:
    • Перетягніть колонку context у блок Features (Ознаки).
    • Перетягніть колонку next_token у блок Target Variable (Цільова змінна).
  2. Векторизація тексту: Використайте віджет Bag of Words або TF-IDF для перетворення текстового контексту на числові вектори частот слів.
  3. Навчання класифікатора: Підключіть моделі Naive Bayes (Наївний Байєс) та Logistic Regression (Логістична регресія).
  4. Оцінка якості (Test & Score): Перевірте точність передбачення моделі за методом крос-валідації (Cross Validation: 5-fold).
  5. Інтерактивне передбачення (Predict): Введіть новий тестовий контекст (наприклад, "штучний інтелект") та подивіться, яке слово модель виведе з найвищою ймовірністю!

💻 Альтернатива на Python: Простий Trigram-генератор

Якщо ви бажаєте реалізувати подібну модель кодом, ось компактний приклад на Python:

from collections import defaultdict, Counter
import random

corpus = "штучний інтелект змінює світ штучний інтелект відкриває нові горизонти штучний інтелект допомагає людям"
words = corpus.split()

# Створюємо словник триграм: (w1, w2) -> Counter(наступні_слова)
trigrams = defaultdict(Counter)
for i in range(len(words) - 2):
    ctx = (words[i], words[i+1])
    target = words[i+2]
    trigrams[ctx][target] += 1

def predict_next_word(w1, w2):
    candidates = trigrams.get((w1, w2))
    if not candidates:
        return None
    # Обираємо найімовірніше слово
    return candidates.most_common(1)[0][0]

context = ("штучний", "інтелект")
predicted = predict_next_word(*context)
print(f"Контекст: {context} -> Прогноз моделі: '{predicted}'")
✅ Висновки та критерії звіту:
  • Як розмір контексту впливає на точність: більший контекст дає точніші передбачення, але вимагає експоненційно більшого обсягу навчальних даних.
  • Зв'язок із сучасними LLM: моделі сімейства GPT роблять абсолютно те саме, але використовують контекст у тисячі слів та мільярди нейропараметрів у механізмі Attention замість простого підрахунку триграм.
