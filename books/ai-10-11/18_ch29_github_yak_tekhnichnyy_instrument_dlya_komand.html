GitHub — це глобальна платформа для спільної розробки, управління вихідним кодом та контролю версій на основі Git. Вона є фактичним індустріальним стандартом у сфері Software Engineering та штучного інтелекту, забезпечуючи відстеження історії змін, ревʼю коду, інтеграцію та публікацію проєктів.

Системи контролю версій: Основи Git

Git дозволяє розробникам зберігати знімки (snapshots) стану файлів проєкту, створювати незалежні гілки для тестування нових експериментів та безболісно об'єднувати результати роботи багатьох учасників команди в основну гілку (main/master).

🌿 Робота з гілками (Branching)

Гілки дозволяють ізолювати розробку нових функцій від стабільного коду. Кожен розробник працює у своїй гілці (feature-branch), після чого створює Pull Request для перевірки та злиття (merge).

☁️ Хмарне середовище: GitHub Codespaces

Повноцінна VS Code розробка безпосередньо у веб-браузері з попередньо встановленим Linux-середовищем, Python та Git без потреби локальної інсталяції на комп'ютер.

Практична робота: Створення GitHub-портфоліо та публікація першого проєкту

Покрокові інструкції:

  1. Створіть власний обліковий запис на GitHub.com (якщо у вас його ще немає).
  2. Створіть публічний репозиторій для ваших навчальних проєктів із ШІ під назвою ai-projects.
  3. Додайте стартовий файл README.md з описом вашого портфоліо та цілей навчання на курсі.
  4. Завантажте шаблон структури проєкту або створіть власну веб-візитку з використанням GitHub Pages.
