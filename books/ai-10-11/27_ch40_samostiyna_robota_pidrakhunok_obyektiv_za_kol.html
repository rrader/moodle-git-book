У цьому самостійному практичному завданні ми розробимо алгоритм комп'ютерного зору для автоматичного підрахунку кількості риб на підводному зображенні, поєднуючи фільтрацію за кольором у просторі HSV та геометричну селекцію за площею контуру (contourArea).

🛠 Ключові етапи реалізації алгоритму:

1. Сегментація за кольором у просторі HSV

Простір HSV (Hue, Saturation, Value) набагато стійкіший до коливань освітленості під водою, ніж звичайний RGB/BGR. Виділимо помаранчевий колір риб за допомогою маски діапазону cv2.inRange(): 

import cv2
import numpy as np

# 1. Зчитуємо зображення
img = cv2.imread('fish.jpg')

# 2. Конвертуємо зображення з BGR у HSV
hsv = cv2.cvtColor(img, cv2.COLOR_BGR2HSV)

# 3. Визначаємо помаранчевий діапазон:
# H: 10-20 для помаранчевого відтінку
# S: 100-255 щоб відсіяти бліді кольори
# V: 100-255 щоб відсіяти темні тіні
lower_orange = np.array([10, 100, 100])
upper_orange = np.array([20, 255, 255])

# Створюємо бінарну маску
mask = cv2.inRange(hsv, lower_orange, upper_orange)

2. Фільтрація знайдених контурів за площею (cv2.contourArea)

На бінарній масці можуть з'явитися дрібні шумові цятки або великі фонові плями. Щоб врахувати виключно риб, ми фільтруємо контури за мінімальним та максимальним розміром: 

# 4. Знаходимо зовнішні контури
contours, _ = cv2.findContours(mask, cv2.RETR_EXTERNAL, cv2.CHAIN_APPROX_SIMPLE)

# 5. Фільтруємо контури за площею
MIN_AREA = 500   # мінімальна площа контуру риби
MAX_AREA = 5000  # максимальна площа

valid_fish_contours = []
for contour in contours:
    area = cv2.contourArea(contour)
    if MIN_AREA < area < MAX_AREA:
        valid_fish_contours.append(contour)

fish_count = len(valid_fish_contours)
print(f"Кількість виявлених риб: {fish_count}")
